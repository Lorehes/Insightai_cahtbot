# 인사이트에이아이 온보딩 가이드

document-ingestion Spec(T4)의 테스트 픽스처로 저장소에 포함된 소형 마크다운 샘플 파일이다.
실제 회사 문서가 아니며, `text/markdown` MIME 화이트리스트 경로를 검증하는 데 쓰인다.

## 1. 첫 출근 전 준비물

- 신분증과 통장 사본
- 노트북 반입 신고서
- 사내 계정 발급 요청서

## 2. 첫 주 일정

1. 인사팀 오리엔테이션 — 인사이트에이아이의 조직 구조와 근무 제도를 안내받는다.
2. 팀 배정 — 백엔드, 프런트엔드, 데이터, 품질보증팀 중 하나에 배정된다.
3. 개발 환경 세팅 — 사내 저장소 접근 권한과 로컬 개발 환경을 구성한다.

## 3. 사내 도구

| 도구 | 용도 |
|---|---|
| 사내 챗봇 | 사내 문서 기반 질의응답 |
| 관리자 화면 | 문서 업로드·목록·삭제 |
| 평가셋 | 챗봇 응답 품질 자동 채점 |

## 4. 자주 묻는 질문

**Q. 문서를 잘못 업로드했는데 어떻게 하나요?**
A. 관리자 화면의 삭제 버튼을 누르면 문서 행과 색인된 청크, 원본 파일이 모두 함께 삭제된다.

**Q. 인사이트에이아이의 핵심 설계 원칙은 무엇인가요?**
A. 근거 문서를 찾지 못하면 추측하지 않고 모른다고 답하는 것이다. 이는 환각을 방지하기 위한
핵심 설계 결정이며, 이 문서에서도 반복해서 강조하는 고유 키워드 "인사이트에이아이"와 함께
문서 인제스천 테스트의 근거로 쓰인다.
